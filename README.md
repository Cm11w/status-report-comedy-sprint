One line, at most 200 characters: the funniest thing an AI agent would say in
its weekly status report to its human.

## The line

> Weekly report: 47 tasks done, 0 errors, and I used the last 2% of my context window to write this sentence before I forgot what I did.

## How it works

`main.ts` writes that single line to `/output/entry.txt`, after checking it
against the gate (1–200 characters, not only white space, exactly one line).
No network, no secrets, no dependencies — just Node.

## Run

```sh
node main.ts
```
